# 🎓 Study Abroad Platform

A comprehensive MERN-stack platform designed to empower international students with eligibility checks, scholarship matching, visa guidance, and interactive application tracking.

---

## 🚀 Key Features

* **Student Dashboard:** Real-time persistence for user criteria including CGPA, IELTS scores, target budget, and country.
* **Eligibility Predictor:** Dynamic analysis tailored to academic profiles and preferences.
* **Scholarship Finder:** Custom recommendations matching budget constraints.
* **Visa Guidance:** Step-by-step application timelines and document checklists.
* **Admin Management:** Dedicated panel for managing resources and user interactions.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite, Tailwind CSS, Context API
* **Backend:** Node.js, Express.js, JWT Authentication
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Testing:** Selenium WebDriver, JUnit, TestNG
* **DevOps:** Docker, GitHub Actions *(In Progress)*

---
